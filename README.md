# 오작교 — 웹매거진 디자인

## 열어 보기
압축을 해제한 뒤 index.html을 브라우저에서 여세요. 별도 설치나 빌드가 필요하지 않습니다.

## 구성
- index.html: 웹매거진 표지, 사진 기사 카드, 기존 프로젝트 전체 콘텐츠
- magazine.css: 공통 디자인과 모바일 화면 스타일
- report.html: 연구보고서와 요약서
- img/: 기존 사진 59장

## 디자인
따뜻한 종이색, 짙은 녹색, 명조체 제목, 사진 중심 표지, 상단 메뉴, 편집자 노트로 구성했습니다. 상세 페이지와 보고서에도 공통 스타일을 적용했습니다.
기존 탭, 사진 확대, 자료실 입력/인쇄 기능의 JavaScript와 원래 인쇄용 스타일은 유지했습니다.

## 기존 사이트에 적용
index.html, report.html, magazine.css, img 폴더를 같은 위치에 함께 업로드하세요.
Google Fonts와 외부 영상은 인터넷 연결이 필요합니다. 글꼴 연결이 안 되면 시스템 글꼴을 사용합니다.

## 확인 범위
로컬 이미지/스타일 파일 연결, 내부 링크, JavaScript 구문을 검사했습니다.
브라우저 실행이 환경에서 제한되어 실제 화면 및 클릭 동작 검증은 완료하지 못했습니다.
